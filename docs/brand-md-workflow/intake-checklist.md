# brand.md Intake Checklist

Ask for the brand name and provided references. Accept:
- PDFs / brand guides
- image files
- videos
- URLs
- official or owner-approved social post URLs / screenshots
- decks / presentations
- logos / icons / asset packs

For each asset, record:
- ID: `S01`, `S02`, etc.
- Source name
- File path or URL
- Type
- Date / recency if known
- Authority: official, owner-provided, owner-approved context, or lower-authority reference
- Intended use context
- Notes / caveats

Do not collect arbitrary extra assets unless the owner/reviewer explicitly provides or approves them.
