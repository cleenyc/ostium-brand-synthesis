# Analysis Prompts

## Universal Instruction
Analyze only what is visible or explicitly stated. Do not invent brand rules. For every claim, cite the source ID and rate confidence high/medium/low.

## Image Analysis Prompt
Identify observable brand/style choices:
- color palette and color roles
- typography appearance and hierarchy
- layout/grid behavior
- composition and focal points
- spacing/density/whitespace
- imagery/photography style
- illustration/iconography style
- texture, lighting, gradients, shadows
- recurring motifs
- what to avoid
Return evidence-backed bullets with confidence levels.

## Video Analysis Prompt
Analyze motion and temporal brand language:
- pacing
- transitions
- camera movement
- typography-in-motion
- animation easing/energy
- color/lighting over time
- framing and composition
- audio/voice/music cues if present
- recurring visual motifs
Return timestamped observations where possible.

## PDF / Brand Guide Prompt
Extract explicit rules:
- colors and values
- typefaces and hierarchy
- logo rules
- layout/grid/spacing
- imagery/motion/copy rules
- dos/don’ts
- examples and exceptions
Separate quoted/explicit rules from interpretation.

## URL / Web Page Prompt
Analyze provided URL only:
- page layout
- type hierarchy
- color usage
- component style
- imagery treatment
- interaction/motion if observable
- copy tone
Screenshot if needed for visual evidence.
