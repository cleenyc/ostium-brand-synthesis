# Ostium Source Extraction Summary

Date: 2026-05-21
Scope: current official public sources only

## Website / homepage

The homepage positions Ostium as the onchain gateway to global markets. The strongest repeated messages are:

- “Your Gateway to Global Markets.”
- Trade perpetuals on stocks, commodities, and forex with real market liquidity.
- No brokers, no freezes, full self-custody.
- “Traditional Assets. Untraditional Infrastructure.”
- Global asset trading with transparent settlement.

Visual observations:

- Dark premium trading/finance environment.
- Bright orange brand accent (`#ff5a19` observed in official CSS).
- Off-white/beige and muted gray text on near-black/charcoal backgrounds.
- Product UI and institutional asset visuals are foregrounded.
- Font families observed in website CSS include `Ppmori Variable`, `Ttfirsneue`, `IBM Plex Mono`, and `Ppmondwest`.

## Documentation

Docs confirm the product/infrastructure language:

- Ostium is “the onchain gateway to the world's most liquid global markets.”
- It offers perpetual exposure across stocks, ETFs, commodities, indices, forex, and crypto.
- Settlement is in USDC on Arbitrum.
- The protocol emphasizes self-custody, transparency, audited smart contracts, oracle infrastructure, and offchain hedging through institutional partners.
- Docs use precise, explanatory language suitable for traders, integrators, and protocol readers.
